# Online Quiz System 

A full-stack Online Quiz System built using:

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript
- JWT Authentication

## Features

- User Authentication  
- Multiple Quiz Categories
- Dynamic Quiz Timer  
- Auto Submit on Timeout  
- Leaderboard System  
- Quiz Result Analytics  
- Responsive UI  
- MySQL Database Integration  

## Quiz Categories

- Java Quiz
- Python Quiz
- AWS Quiz
- Networking Quiz
- Web Development Quiz

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js

### Database
- MySQL

## Installation

### Clone Repository

```bash
git clone <repo-url>
```

### Install Backend Dependencies

```bash
cd server
npm install
```

### Configure Environment Variables

Create `.env`

```env
PORT=4000

DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=quiz_app

JWT_SECRET=your_secret
```

### Run Backend

```bash
npm run dev
```

### Run Frontend

Open with Live Server.
