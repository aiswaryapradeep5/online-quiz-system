# Online Quiz System (Node.js + Express + MySQL)

A full-stack Online Quiz System with secure backend architecture,
role-based authentication, server-controlled quiz timing, and a static frontend.

---

## Tech Stack

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication (bcrypt + role-based access control)

### Frontend
- HTML
- CSS
- JavaScript (Vanilla)

---

## Features

- User & Admin authentication (JWT)
- Role-based access control (`user`, `admin`)
- Admin CRUD for quizzes, questions, and options
- Server-controlled quiz timer (prevents client-side manipulation)
- Secure answer handling (correct answers never sent to users)
- Score calculation on backend
- Quiz attempt tracking and history
- Responsive UI
- MySQL relational schema with foreign keys
